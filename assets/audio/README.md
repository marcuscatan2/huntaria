# Original local audio assets

Three mono 22,050-Hz, 16-bit, 16-second WAV loops are generated by
[audio_assets.py](../../scripts/audio_assets.py). The checked-in note sequences
and synthesis envelopes are original project code, not copied songs or samples.
No voice, stock library, remote audio request or paid generation service is used.

`python scripts/audio_assets.py --check` compares each PCM sample with the score.
The client build manifest hashes the actual exported files. `audio.js` defines
the short procedural cue bank separately; settings route through
[preferences/audio](../../features/experience/SETTINGS_AUDIO.md).

Human mix/music acceptance remains pending. This provenance record documents
the source method; it is not a blanket legal clearance for the entire game.
