## Symptoms

| Symptom | Start here | If the fault crosses the boundary |
| --- | --- | --- |
| Wrong pose, sliding, missing frames | [animation](<features/animation/README.md>) | [world-facing](<docs/architecture/CONNECTIONS.md#world-facing>) |
| Damage number / sound arrives before impact | [animation](<features/animation/README.md>) | [combat-feedback](<docs/architecture/CONNECTIONS.md#combat-feedback>) |
| Wrong target, reach, damage or cooldown | [combat](<features/combat/README.md>) | [derived-stats](<docs/architecture/CONNECTIONS.md#derived-stats>) |
| Invisible bridge, blocked road, bad atlas destination | [exploration](<features/exploration/README.md>) | [world-collision](<docs/architecture/CONNECTIONS.md#world-collision>) |
| Duplicate/lost loot, Echo or replay rewards | [persistence](<features/persistence/README.md>) | [encounter-settlement](<docs/architecture/CONNECTIONS.md#encounter-settlement>) |
| Same-species copies overwrite each other | [party](<features/party/README.md>) | [owned-build](<docs/architecture/CONNECTIONS.md#owned-build>) |
| Monster respawns beside the kill or rerolls | [population](<features/population/README.md>) | [spawn-reservation](<docs/architecture/CONNECTIONS.md#spawn-reservation>) |
| Switching builds heals / recovery not working | [recovery](<features/recovery/README.md>) | [injury-and-supplies](<docs/architecture/CONNECTIONS.md#injury-and-supplies>) |
| Quest not advancing / pack replay wrong | [campaign](<features/campaign/README.md>) | [campaign-encounter](<docs/architecture/CONNECTIONS.md#campaign-encounter>) |
| Creator repeats, wrong name, hair or starter weapon | [opening](<features/opening/README.md>) | [created-apprentice](<docs/architecture/CONNECTIONS.md#created-apprentice>) |
| Creature attacks through a wall or while a menu is open | [exploration](<features/exploration/README.md>) | [territorial-encounter](<docs/architecture/CONNECTIONS.md#territorial-encounter>) |
| Sound stuck, duplicate music, settings not retained | [experience](<features/experience/README.md>) | [device-presentation](<docs/architecture/CONNECTIONS.md#device-presentation>) |
| Wrong displayed companion, lost decoration or failed picture export | [inner-sea](<features/inner-sea/README.md>) | [haven-layout](<docs/architecture/CONNECTIONS.md#haven-layout>) |

`python scripts/project.py context combat` returns the focused route.
Also accepts a source path, exported global, F-### card or connection ID.
`python scripts/project.py impact game.js` expands the affected consumers/tests.
Current acceptance cards remain in [FEATURE_BACKLOG](FEATURE_BACKLOG.md);
each feature guide lists its cards. This index does not accept any criterion.

Regenerate with `python scripts/project.py map --write` after ownership,
interface or test-routing changes; `python scripts/project.py check` detects drift.
